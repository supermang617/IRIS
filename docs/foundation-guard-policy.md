# Foundation Guard Policy

Status: active.

The foundation guard is the canonical local regression gate for the current Iris prototype.

It checks:

- no interactive development prompts
- runtime safety boundary
- manifest safety wording
- format
- build
- workspace tests
- addressee intent
- deictic ownership
- voice ownership
- profanity fidelity
- xtask audit

## Deictic ownership rule

When the user says "I am proud of you" to Iris, Iris must understand that the user is proud of Iris.

Acceptable response:

"Thank you. I'm proud I passed, too."

Forbidden responses:

- "I'm glad you passed."
- "You did great."
- "I'm glad you're proud of yourself."
